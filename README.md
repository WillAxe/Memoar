It’s a web app where you can create **photo albums (called rooms)**, upload pictures, and share them with others. Just create a room and you’re ready to go.

**Note:** Memoar is still under active development. Some features may be incomplete, buggy, or subject to change.

---

##  Features

- Create photo albums (rooms)
- Upload and organize photos
- Share rooms with others
- Simple and lightweight interface

More features are coming soon!

---

## ⚠️ Important Security Notice

This is a development-stage project, security improvements are still being worked on.

**Passwords are however encrypted**
